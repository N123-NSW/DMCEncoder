# APM32 编码器模拟器 —— 使用手册

| 项目 | 说明 |
|---|---|
| 主控 | APM32F103（极海，STM32F103 兼容） |
| 开发环境 | Keil MDK v5.37 + ARM Compiler 5.06 + Geehy APM32F1xx_DFP 器件包 |
| 工程文件 | `Project\5220-apm32.uvprojx` |
| 功能 | 模拟 TAMAGAWA(多摩川) T-format 绝对值编码器，RS485 响应上位机轮询 |
| 角度源 | 昆泰芯 KTM5220 AMR 磁编码芯片（SPI，21bit 绝对角度） |
| 存储 | GT24C64A EEPROM（I2C，存放配置/校准数据） |

## 1. 硬件资源与引脚接线

### 1.1 引脚分配

| 功能 | MCU 引脚 | 外设 | 配置 | 连接 |
|---|---|---|---|---|
| SPI1_SCK | PA5 | SPI1 | 复用推挽 50MHz | KTM5220 → SCK |
| SPI1_MISO | PA6 | SPI1 | 输入上拉 | KTM5220 → MISO |
| SPI1_MOSI | PA7 | SPI1 | 复用推挽 50MHz | KTM5220 → MOSI |
| SPI1_CS | PA4 | GPIO | 推挽输出（软件片选） | KTM5220 → CS（低有效） |
| I2C1_SCL | PB6 | I2C1 | 复用开漏 | GT24C64A → SCL |
| I2C1_SDA | PB7 | I2C1 | 复用开漏 | GT24C64A → SDA |
| USART1_TX | PA9 | USART1 | 复用推挽 | RS485 收发器 DI |
| USART1_RX | PA10 | USART1 | 浮空输入 | RS485 收发器 RO |
| 485_DE | PA12 | GPIO | 推挽输出 | 收发器 DE（高=发送） |
| 485_RE | PA11 | GPIO | 推挽输出 | 收发器 RE（低=接收） |
| ALARM | PB5 | GPIO | 下拉输入 | 外部故障信号（高=故障） |

### 1.2 关键通信参数

| 接口 | 参数 |
|---|---|
| SPI（KTM5220） | 主机、**Mode 3**（CPOL=1/CPHA=1）、8bit、MSB first、4.5MHz |
| I2C（GT24C64A） | 硬件主机 400kHz、7bit 地址 `0x50` |
| RS485（USART1） | 默认 **2.5Mbps**，8 数据位 + 1 停止位、无校验（8N1），DMA 收发 |
| KTM5220 电源 | 3~5.5V（工程供电 VCC） |

> **波特率切换**：`main.c` 顶部 `#define satus 0`。
> `satus=0` → 2500000（联机用）；`satus=1` → 115200（串口调试用）。
> 改完需重新编译。

> **SCL/SDA 上拉**：I2C 为开漏，PB6/PB7 需外部 4.7kΩ 上拉到 VCC，否则 I2C 通信失败。

## 4. 上位机联调

接线完成后上电，复位 10ms 后开始工作。上位机按 T-format 从站寻址即可读取：

- 角度轮询地址：`ID0 (0x02)`，62.5us 周期即可（本工程响应零 SPI 等待）。
- 如需验证角度变化，转动 KTM5220 上方磁钢，`ABS0/1/2` 应变。

**自测方法**（临时）：`main.c` 中把 `#define MEASURE_I2C 1` 后重新编译，程序会每 100ms
读一次 KTM52 角度并经 485 发一帧 ID0 响应，可用示波器/串口助手观察；测完改回 `0`。

## 5. 通信协议（T-format 帧格式）

帧由若干 **数据字** 组成，每个数据字：1 起始位 + 8 数据位 + 1 停止位，**低位在前**。
CRC-8 多项式 `x8+1`：对 CRC 前所有数据字节做**异或**。

### 5.1 命令 / 响应表

| 命令 | CF 码 | 请求 Req | 响应 Resp | 说明 |
|---|---|---|---|---|
| ID0 读单圈位置 | `0x02` | `[CF]` | `[CF+SF+DF0+DF1+DF2+CRC]` | DF0~2=ABS0/1/2 |
| ID2 读 ID | `0x92` | `[CF]` | `[CF+SF+DF0+CRC]` | DF0=ENID |
| ID3 读全部信息 | `0x1A` | `[CF]` | `[CF+SF+DF0..DF7+CRC]` | ABS、ENID、ALMC 等 |
| ID4 快速自校准 | `0x03` | `[CF]` | `[CF+CorrectionStatus]` | 需转满 16 圈，耗时较长 |
| ID5 慢自校准 | `0x04` | `[CF]` | `[CF+CorrectionStatus]` | 需转满 16 圈，耗时较长 |
| ID6 写 E2PROM | `0x32` | `[CF+ADF+EDF+CRC]` | `[CF+ADF+EDF+CRC]` | 立即回显，后台落盘 |
| IDD 读 E2PROM | `0xEA` | `[CF+ADF+CRC]` | `[CF+ADF+EDF+CRC]` | 忙时 EDF=0 |
| ID7 多圈位置归零 | `0x62` | `[CF]` | `[CF+SF+DF0+DF1+DF2+CRC]` | 后台执行归零 |
| ID8 单圈位置归零 | `0xC2` | `[CF]` | `[CF+SF+DF0+DF1+DF2+CRC]` | 后台执行归零 |
| IDC 故障复位 | `0xBA` | `[CF]` | `[CF+SF+DF0+DF1+DF2+CRC]` | 后台清除 ALMC |
| 其它/非法 CF | - | - | `[ID3(0x1A)+0x00+0x00+CRC]` | 异常响应 |

- 归零（ID7/ID8）与故障复位（IDC）**先立即回单圈角度帧，再在后台慢慢执行**，
  因此归零/复位期间上位机可连续以 62.5us 周期发多次，每次都收到最新单圈信息。
- 归零实际动作：向 KTM5220 寄存器 `0x12` 写 1（软件置零，当前机械角映射为零点），
  由 `KTM52_SetZero()` 完成，仅改 RAM 不写 MTP。

### 5.2 SF（Status Field）状态字

| bit | 含义（置 1 = 有错） |
|---|---|
| bit4 | 过热 / 多圈错误 |
| bit5 | 电池错误 / 电池预警 |
| bit6 | 请求帧奇偶校验错误 |
| bit7 | 请求帧定界符错误 |

### 5.3 ALMC 故障字

| bit | 含义 |
|---|---|
| bit2 | 单圈获取失败（KTM52 读角度 CRC 校验失败） |
| bit7 | PB5 引脚输入高电平 = 故障 |

故障位为**锁存**语义：故障触发后置 1，收到 IDC（故障复位）后清除；若故障条件
仍然存在（PB5 仍高 / CRC 仍失败），后台会再次置位。

## 6. E2PROM 页模型

- 虚拟 E2PROM = **8 页 × 127 字节 = 1016 字节**，落盘到 GT24C64A 物理地址 `0~1015`
  （芯片共 8KB，余量充足）。
- 地址空间：`0~126` = 当前页数据；`127` = **页寄存器**（写它来切换当前页）。
- 写入路径：ID6 → 立即回显 → 写 RAM 镜像并置脏位 → 后台逐字节回写（每次 1 字节，
  等待 EEPROM 内部 ~5ms 编程完成后通过 ACK 轮询清脏位），**上电后默认页 0**，
  `Encoder_EEPROM_Load()` 会把整片 1016B 载入 RAM 镜像。

## 7. 后台任务说明（Encoder_AnglePoll，主循环每轮调用）

1. **非阻塞读角度**：SPI 空闲时启动 6 字节 DMA 读 KTM5220，完成后锁存
   `abs_pos`（21bit 角度快照）；CRC 失败置 ALMC.bit2。
2. **后台归零**：收到 ID7/ID8 只打标志，待角度 DMA 空闲时执行 `KTM52_SetZero()`。
3. **后台故障复位**：收到 IDC 后清 `almc`。
4. **ALARM 检测**：每轮读 PB5，为高则置 ALMC.bit7。
5. **EEPROM 回写**：把 RAM 镜像中的脏字节逐个、非阻塞地写回 GT24C64A。

## 9. 常见故障排查

| 现象 | 排查方向 |
|---|---|
| RS485 无通信 | 波特率是否 2.5M（`satus=0`）；DE/RE 方向；A/B 是否接反；上位机是否以 T-format 从站寻址 |
| 角度一直为 0 或不变 | KTM5220 是否接好、供电；SPI 是否 **Mode3**；CS 是否为 PA4 且拉低 |
| KTM5220 CRC 经常失败 / ALMC.bit2=1 | SPI 速率降到 `SPI_BAUDRATE_DIV_64`(1.125MHz) 验证线材/信号；核对磁钢磁场范围 20~150mT |
| EEPROM 写入不生效 | PB6/PB7 是否有 4.7kΩ 上拉；I2C 是否 400kHz 以内；写后是否等 5ms |
| ALMC.bit7 常置位 | PB5 是否被外部拉高；若无需此功能，悬空或拉低 PB5 |
| 归零后角度无变化 | 确认是否收到 ID7/ID8；检查 KTM5220 寄存器是否被写保护（需先 `KTM52_UnlockReg`） |
| 编译报缺芯片/头文件 | 安装 Geehy APM32F1xx_DFP 器件包 |
