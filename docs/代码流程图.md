# APM32 编码器模拟器 —— 代码流程图（当前版本）

> 本图反映**最新优化后**的代码逻辑：RS485 接收采用 **RXNE 逐字节中断 + 状态机**，
> 读角度命令（ID0/ID3）响应帧**后台预组装**、中断内**零组装直发**，追求 ≤3us 响应。

涉及文件：`main.c`、`uart.c/.h`、`485.c/.h`、`spi.c`、`ktm52.c`、`i2c.c`、`gt24c64a.c`

---

## 3. 主循环流程（main.c）

```mermaid
flowchart TD
    LOOP["while(1)"] --> P["Encoder_AnglePoll()<br/>(见第 7 节: 后台读角度+预组装+EEPROM)"]
    P --> Q{"rx_data != 0?<br/>(ID4/ID5 自校准置位)"}
    Q -->|"是"| R["rx_data=0<br/>Encoder_ProcessRx(RX_DATA,RX_LEN)<br/>处理 ID4/ID5 自校准"]
    R --> LOOP
    Q -->|"否"| LOOP
```

> 注意：ID0/2/3/6/D/7/8/C 等命令**全部在 USART1 中断里处理完**，不再走主循环；
> 只有 ID4/ID5（自校准，阻塞数百 ms）通过 `rx_data` 标志交主循环。

## 4. USART1 中断处理（uart.c，核心）

```mermaid
flowchart TD
    IRQ["USART1_IRQHandler 进入"] --> C1{"读 STS<br/>RXBNE 置位?"}

    C1 -->|"是"| R1["读 DR 得字节 b<br/>s_rx_buf[s_rx_cnt]=b, s_rx_cnt++"]
    R1 --> R2{"s_rx_cnt==1?<br/>(首字节)"}
    R2 -->|"是"| R3["s_rx_need = GetFrameLen(b)<br/>ID6=4 / IDD=3 / 其余=1"]
    R2 -->|"否"| R4
    R3 --> R4{"s_rx_cnt >= s_rx_need?<br/>(收满一帧)"}
    R4 -->|"否"| END["中断返回(继续收)"]
    R4 -->|"是"| R5{"cf == ID3(0x1A)?"}

    R5 -->|"是"| HOT["<b>ID3 热路径</b>(零函数调用)<br/>见第 5 节"]
    R5 -->|"否"| R6["Encoder_HandleFrameISR(buf,len)<br/>见第 6 节"]
    HOT --> R7["s_rx_cnt=0, s_rx_need=0"]
    R6 --> R7
    R7 --> END

    C1 -->|"否"| C2{"IDLE 置位?"}
    C2 -->|"是"| I1["清 IDLE + 读 DR<br/>复位状态机(s_rx_cnt=0)"]
    I1 --> END

    C2 -->|"否"| C3{"ERR(溢出/帧错误)?"}
    C3 -->|"是"| E1["usart_err_cnt++<br/>读 DR 清标志<br/>复位状态机"]
    E1 --> END
    C3 -->|"否"| END
```

## 5. ID3 热路径（中断内零函数调用直发）

```mermaid
flowchart TD
    S["收到 ID3 命令"] --> A["id3 = Encoder_GetTxID3()<br/>(取预组装缓冲指针)"]
    A --> B["USART1->CTRL1 &= ~(RXBNE|IDLE)<br/>禁接收中断"]
    B --> C["GPIOA->BSC = PA12|PA11<br/>切 TX 方向(DE+RE 高)"]
    C --> D["for i=0..10:<br/>等 TXBE 后 USART1->DATA=id3[i]<br/>(直接写 TDR, 11 字节)"]
    D --> E["等 TC(发送完成)"]
    E --> F["GPIOA->BC = PA12|PA11<br/>切回 RX(DE+RE 低)"]
    F --> G["读 STS + 读 DR 清 ORE/IDLE"]
    G --> H["USART1->CTRL1 |= (RXBNE|IDLE)<br/>重新使能接收中断"]
    H --> I["中断返回"]
```

> 特点：整个 ID3 响应**不经过任何函数调用和库函数**，只做直接寄存器操作，
> 把响应延迟压到最低（这是从 5us 优化到 3us 的关键）。

## 6. 命令处理（Encoder_HandleFrameISR，非 ID3 命令）

```mermaid
flowchart TD
    S["Encoder_HandleFrameISR<br/>cf = buf[0]"] --> SW{switch cf}

    SW -->|"ID0 0x02 读单圈"| A0["Encoder_SendBuffer(s_tx_id0,6)<br/>预组装帧直发"]
    SW -->|"ID2 0x92 读ID"| A2["组装 ID2+SF+ENID+CRC<br/>Encoder_485_Senddata(4)"]
    SW -->|"ID3 0x1A"| A3["Encoder_SendBuffer(s_tx_id3,11)<br/>(通常走中断热路径, 此分支为兜底)"]
    SW -->|"ID6 0x32 写E2PROM"| A6["回显 ID6+ADF+EDF+CRC<br/>+ EE_WriteOne 后台脏写"]
    SW -->|"IDD 0xEA 读E2PROM"| AD["回 IDD+ADF+EDF+CRC"]
    SW -->|"ID7 0x62 多圈归零"| A7["zero_pending=1<br/>回 ID7+SF+ABS+CRC"]
    SW -->|"ID8 0xC2 单圈归零"| A8["zero_pending=1<br/>回 ID8+SF+ABS+CRC"]
    SW -->|"IDC 0xBA 故障复位"| AC["alarm_reset_pending=1<br/>回 IDC+SF+ABS+CRC"]
    SW -->|"ID4/ID5 自校准"| A45["拷贝到 RX_DATA 置 rx_data<br/>交主循环(阻塞数百ms)"]
    SW -->|"未知 CF"| DF["异常帧: 回 ID3+0+0+CRC"]
```

## 7. 后台轮询（Encoder_AnglePoll，主循环每轮调用）

```mermaid
flowchart TD
    START["Encoder_AnglePoll()"] --> T1{"alarm_reset_pending?"}
    T1 -->|"是"| T1A["almc=0, 清标志"]
    T1 -->|"否"| T2
    T1A --> T2{"zero_pending && !busy?"}
    T2 -->|"是"| T2A["zero_pending=0<br/>KTM52_SetZero() 写零点"]
    T2 -->|"否"| T3
    T2A --> T3{"角度读取状态?"}
    T3 -->|"!busy"| T3A["KTM52_StartAngle() 启动DMA读<br/>busy=1"]
    T3 -->|"busy且DMA完成"| T3B["KTM52_FinishAngle() 锁存 abs_pos<br/>CRC失败->almc.bit2<br/>busy=0"]
    T3 -->|"busy未完成"| T4
    T3A --> T4
    T3B --> T4["PB5 高? -> almc.bit7 锁存"]
    T4 --> T5["EEPROM 脏字节后台回写<br/>(脏计数>0 才扫, 无脏 O(1) 跳过)"]
    T5 --> T6["<b>Encoder_PrepareResponses()</b><br/>预组装 ID0/ID3 响应帧(含最新角度/CRC)"]
    T6 --> RET["返回"]
```

## 8. 读角度命令完整时序（RXNE 中断 → 响应）

```mermaid
sequenceDiagram
    participant H as 上位机
    participant U as USART1(中断)
    participant M as APM32

    H->>M: ID3 请求字节(0x1A, 1字节=4us)
    Note over M: RXNE 在停止位采样后置位
    M->>U: RXNE 中断触发
    U->>U: 读 DR + 状态机(收满1字节)
    U->>U: 切TX + 直接写11字节TDR(预组装帧)
    M->>H: 响应帧(11字节=44us)
    Note over M,H: 响应延迟=停止位结束→响应起始位(目标3us)
```

## 9. 关键全局变量 / 缓冲

| 名称 | 位置 | 说明 |
|---|---|---|
| `s_rx_buf[8]` | uart.c | 接收状态机字节缓冲 |
| `s_rx_cnt` / `s_rx_need` | uart.c | 已收字节数 / 本帧总字节数 |
| `s_tx_id0[6]` / `s_tx_id3[11]` | 485.c | 预组装响应帧（后台更新） |
| `g_encoder` | 485.c | 编码器上下文（abs_pos/sf/almc/enid/后台标志） |
| `DMA_USART1_TxBuf[64]` | uart.c | 通用发送缓冲（非预组装命令用） |
| `s_ee_ram[]` / `s_ee_dirty[]` | 485.c | EEPROM RAM 镜像 / 脏位图 |
| `s_ee_dirty_count` | 485.c | 脏字节计数（无脏时 O(1) 跳过扫描） |

## 10. 响应延迟优化历程（供参考）

| 阶段 | 方案 | 延迟 |
|---|---|---|
| 初始 | DMA+IDLE 接收 + 主循环处理 | ~100us（抖动） |
| 优化1 | IDLE 中断内响应 | ~11us |
| 优化2 | RXNE 中断 + 状态机 | ~8us |
| 优化3 | 后台预组装 + 零拷贝直发 | ~5us |
| 优化4 | ID3 中断内直接寄存器操作 | ~3us（目标） |
